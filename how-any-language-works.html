PART 2 · WATCH 4 PROGRAMMERS WRITE THE SAME INSTRUCTION

One Rule, Written 4 Ways

In plain English: "If it's raining, take an umbrella. Otherwise, leave it at home."
That's the entire idea. Below, four different programming languages write down that exact same rule — only the spelling changes.
Different spelling, same thinking. Every version above performs one "Selection" step (if / else) — checking a condition and choosing one of two paths. That's true whether it's Python, JavaScript, Java, or C++.
